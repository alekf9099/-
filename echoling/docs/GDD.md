# ECHOLING (에코링) — 게임 기획서 v0.1

> **한 줄 컨셉**: "출퇴근 15분, 한 판의 몬스터 테이밍 모험."
> 포켓몬류 *몬스터 수집 RPG*의 재미(포획·육성·상성)를 **로그라이크 런 구조**와 **오토배틀러식 시너지**로 재해석한 안드로이드 퍼스트 게임.

---

## 0. 먼저 짚을 것 — IP(지식재산권) 결정

| 선택지 | 결과 |
|---|---|
| ❌ 포켓몬 이름·디자인·브랜드 사용 | 닌텐도/포켓몬컴퍼니는 팬게임에도 적극 대응해 왔음 (예: *Pokémon Uranium*·*Pokémon Prism* 2016년 중단 요청, 2024년 *Palworld* 개발사 대상 특허 소송). **플레이스토어 등록 시 신고 → 삭제 위험 매우 높음.** |
| ✅ **장르 문법만 차용 + 100% 오리지널 IP** | 몬스터 수집·속성 상성·진화는 장르 공통 문법 (저작권 보호 대상 아님). 이름·외형·세계관·시스템은 전부 자체 제작 → **출시·수익화 가능.** |

**→ ECHOLING은 오리지널 IP로 개발.** 몬스터(=에코링) 33종, 기술 50종, 아트는 코드로 생성하는 SVG(외부 이미지 0개)로 전부 자체 제작.
*추가 주의*: 스토어 등록정보·광고 문구에 "포켓몬"이라는 단어를 쓰지 말 것 (키워드 스터핑으로 정책 위반 + 상표 문제).

## 1. 왜 지금 이 게임인가 — 2026 트렌드 분석

| 트렌드 | 시장 신호 | ECHOLING 적용 |
|---|---|---|
| **숏폼 세션** | 모바일 평균 세션 짧아짐. *Balatro*·*Vampire Survivors*처럼 "한 판 15~30분" 로그라이트가 모바일에서 장기 흥행 | 1런 = 3액트 × 11층 ≈ **15~20분**. 노드마다 자동저장 → 언제 꺼도 이어하기 |
| **빌드 시너지의 쾌감** | *TFT*의 시너지, *Balatro*의 조커 조합 → "내가 만든 사기 빌드" 공유 문화 | **공명(Resonance)**: 같은 속성 2/3마리 → 세트 보너스 + **부적 24종** 조합 |
| **몬스터 테이밍 르네상스** | *Cassette Beasts*(2023), *Palworld*(2024) 등 "포켓몬 아닌 몬스터 수집" 수요 확인 | 오리지널 에코링 + **에코 퓨전**(기술·경험치 계승) |
| **데일리 공유 문화** | *Wordle*식 "오늘의 문제" → SNS 공유 | **데일리 챌린지**: 전 세계 동일 시드 + 오늘의 규칙 |
| **반(反) P2W 피로감** | 확률형 아이템 규제 강화 (한국 2024.3 확률 정보 공개 의무화) | **가챠 없음.** 메타 진행은 플레이로만 획득 |
| **한 손·세로 UI** | 지하철 한 손 플레이 표준 | 모든 조작 **하단 엄지 영역**, 최소 터치 48dp, 세로 고정 |
| **오토 + 배속** | 모바일 RPG 기본 UX | ⚡AUTO(최적 기술 자동 선택) + x1/x2/x3 배속 |

### 차별점 요약 (vs 기존 몬스터 로그라이크)
1. **EN(에코 에너지) 전투** — PP 대신 "매 턴 충전되는 진영 공유 에너지". *아끼고 몰아쓰는* 판단이 생김 (카드게임의 마나 커브 감각).
2. **공명 시너지** — 파티 구성 자체가 빌드. "불꽃 3마리 → 공격 시 20% 화상" 같은 세트 효과.
3. **완만한 상성(×1.6)** — 상성 불리 한 번에 런이 끝나는 좌절 제거 (시뮬레이션 근거는 §8).
4. **캐치업 경험치** — 늦게 잡은 에코링도 빠르게 따라잡음 → "새 동료를 써보는" 실험이 손해가 아님.
5. **투명한 확률** — 포획 확률 %, 효과 배지, KO 예측을 버튼에 직접 표시.

## 3. 시스템 상세

### 3.1 전투
- **1:1 턴제**, 파티 최대 6 (초과분 보관함).
- 행동 순서: 우선도 → 스피드(스탯 단계·상태 반영) → 동률 랜덤.
- **EN**: 진영 공유, 시작 1, 매 턴 +1, 최대 3 (*듀얼 코어* 부적 4). 기술 비용 0~3.
  - 0EN 기본기 1개는 **항상 보장** (기술 교체 시 마지막 기본기 잠금) → EN 고갈 소프트락 방지.
- 피해 공식: `((2L/5+2) × 위력 × A/D) / 50 + 2` × 상성 × 자속(1.25) × 공명/부적 × 치명(1.5) × 난수(0.85~1.0)
- **상태이상 5종**: 화상(1/16 지속피해·공격↓) / 중독(1/8) / 감전(스피드½·25% 행동불능) / 빙결(스피드↓·20% 행동불능·3턴) / 수면(1~3턴)
  - 같은 속성 면역 (불꽃→화상 X, 전류→감전 X)
- 스탯 단계 ±4 (공격/방어/스피드), 교체 시 초기화.

### 3.2 속성 (9종) — 2개의 3각 사이클 + 대립쌍
```
사이클 A:  불꽃 → 새싹 → 물결 → 불꽃
사이클 B:  전류 → 바람 → 대지 → 전류
교차:      물결→대지, 대지→불꽃, 새싹→대지, 전류→물결, 불꽃→바람, 바람→새싹
대립쌍:    그림자 ⇄ 빛 (서로 약점, 하이리스크)
무속성:    상성 없음
```
배율: 효과 굉장 **×1.6** / 별로 **×0.625** / 복합 속성은 곱연산 (최대 ×2.56).

### 3.3 공명 (Resonance) — 핵심 차별 시스템
파티 내 같은 속성 수 → 1단계(2마리): 해당 속성 피해 +15% / 2단계(3마리):

| 속성 | 2단계 효과 | 설계 의도 |
|---|---|---|
| 🔥 불꽃 | 공격 시 20% 화상 | 지속딜 |
| 💧 물결 | 매 턴 HP 4% 회복 | 탱킹 |
| 🌿 새싹 | 피해 15% 흡수 | 유지력 |
| ⚡ 전류 | 턴 시작 30% EN +1 | 템포 |
| ⛰️ 대지 | 받는 피해 -15% | 방어 |
| 🌪️ 바람 | 스피드 +25% | 선공 |
| 🌑 그림자 | 치명타 +15%p | 폭딜 |
| ✨ 빛 | 상태이상 면역 | 안정성 |

*공명 증폭기* 부적: 조건 -1 → 하이브리드 빌드 가능.

### 3.4 포획
- 야생 전투에서만. `확률 = 포획률 × (1.6 − HP%) × 상태보정(수면/빙결 1.8, 기타 1.4) × 캡슐(하이퍼 ×2) + 부적`
- 3회 흔들림 연출, 각 흔들림 확률 = p^(1/3) → 긴장감.
- 포획 즉시 **풀HP로 합류** (바로 써볼 수 있게).

### 3.5 성장
- 경험치: `종 기본값 × 적 레벨 / 3.5 × 전투 배율 × 캐치업`
  - **캐치업** = `clamp(1 + (적Lv − 내Lv) × 0.12, 0.3, 2.2)`
  - 참전 100% / 벤치 60% / 기절 30%
- 진화: 레벨 도달 시 모달 → "진화시키기 / 나중에" 선택.
- 기술 4칸, 초과 시 교체 모달.

### 3.6 맵
- 액트당 11행 × 5열, 4갈래 경로 (교차 최소화 알고리즘).
- 행 규칙: 0행 전투 / 5행 보물 / 9행 캠프 / 10행 보스. 엘리트는 4~5행 이후.
- 상점·캠프·엘리트·보물 연속 배치 금지, 맵마다 상점 ≥1 보장.

| 노드 | 내용 |
|---|---|
| ⚔️ 야생 | 1마리, 포획 가능 |
| 🧢 테이머 | 2~3마리 연전, 골드↑, 부적 확률 |
| 💀 엘리트 | 강화 개체, 부적 3택1 |
| ❓ 이벤트 | 8종 텍스트 선택지 |
| 🛒 상점 | 아이템·부적·희귀 에코링 분양, 재진열 |
| ⛺ 캠프 | 휴식(60%회복) / 특훈(+2Lv) / **에코 퓨전** |
| 💎 보물 | 부적 3택1 |
| 👑 보스 | 액트별 전설 에코링 (+호위) |

### 3.7 에코 퓨전 (신규)
한 마리를 떠나보내고 → 그 기술 1개 + 누적 경험치 50%를 다른 에코링에 계승.
"쓸모없어진 초반 포획 몬스터"에게 의미 부여 + 기술 커스터마이징.

### 3.8 메타 진행
- **에코 결정 💎** = 층×2 + 승리 수 + 포획×2 + 액트×25 (+클리어 80)
- 연구소: 시작 골드/캡슐/포션, 스타터 시작 레벨, 상점 진열 수.
- 스타터 해금: 찌릿토(💎120), 그늘쥐(💎200).
- 도감: 목격/포획 기록.

### 3.9 데일리 챌린지
날짜 기반 동일 시드 + 모디파이어 6종 (유리대포 / 골드러시 / 스피드 데몬 / 포획 열풍 / 불꽃 축제 / 아이언맨). 일별 최고 기록 저장.

## 9. 기술 아키텍처

```
echoling/
├─ src/core      타입, 시드 RNG (mulberry32 — 상태 1개 숫자로 저장)
├─ src/data      속성·종·기술·부적·월드 데이터 (순수 데이터)
├─ src/game      전투 엔진·맵 생성·런 진행·이벤트·메타 (DOM 의존 0 → 테스트/시뮬 가능)
├─ src/ui        라우터·컴포넌트·SVG 스프라이트·햅틱/사운드·화면
├─ tests         단위 테스트 + 300런 밸런스 시뮬레이터
└─ capacitor.config.ts  → Android 패키징
```
- **스택**: TypeScript + Vite (프레임워크 없음) + Capacitor 7 (Android WebView)
- **로직/연출 분리**: 엔진은 이벤트 배열 반환 → UI가 순차 재생. 같은 엔진을 봇이 그대로 사용.
- **세이브스컴 방지**: RNG 상태를 런에 저장, 전투 중 저장 안 함 → 재접속 시 동일 조우 재현.
