# ECHOLING v0.2 — 모던 로그라이크 개편 설계서

> 목표: "몬스터 수집 RPG에 맵을 붙인 것"에서 **"매 런마다 다른 빌드가 완성되는 요즘 로그라이크"**로.
> 기준 레퍼런스(장르 문법만 참고): *Slay the Spire*(적 행동 예고·승천), *Balatro*(누적형 빌드 아이템), *Hades*(출발 선택·희귀도 색), *Monster Train*(엘리트 접두사·보스 페이즈).

---

## 1. 진단 — v0.1이 "옛날 게임"처럼 느껴진 이유

| # | 문제 | 플레이어가 느끼는 것 |
|---|---|---|
| 1 | 적이 뭘 할지 모름 | 운에 맡기는 전투, 교체할 이유가 없음 |
| 2 | 런 시작이 매번 똑같음 | 첫 3분이 지루함 |
| 3 | 보스가 "체력 많은 몬스터" | 클라이맥스가 없음 |
| 4 | 엘리트 = 강한 일반 몹 | 위험을 감수할 보상·긴장감 부족 |
| 5 | 부적이 단순 % 증가 | "사기 빌드" 완성의 쾌감 없음 |
| 6 | 클리어 후 할 게 없음 | 장기 리텐션 부재 |
| 7 | 런 결과를 자랑할 수 없음 | 바이럴 경로 없음 |

## 2. 해결 — 7개 시스템

| Phase | 시스템 | 모던 로그라이크 문법 | 우선순위 |
|---|---|---|---|
| **A1** | ⚔️ **적 행동 예고 (Intent)** | 적이 이번 턴 쓸 기술과 예상 피해를 미리 공개 → 보고 교체·방어·선공 판단 | P0 |
| **A2** | 🌅 **출발 축복** | 런 시작 시 3택1 (부적/동료/보급/대가형 계약) | P0 |
| **A3** | 👑 **보스 2페이즈 + 보스 미리보기** | HP 50%에서 분노 각성 (스탯↑, EN 충전). 맵 상단에 이번 액트 보스 공개 | P0 |
| **A4** | 💀 **엘리트 접두사** | 가시·재생·철갑·신속·흡혈·광폭 6종 중 랜덤 부여, 칩으로 표시 | P1 |
| **B1** | 🌈 **전설 부적 + 빌드 아이템 11종** | 누적형(눈덩이), 조건부(외로운 늑대), 1회성(불사조) 등 빌드 정체성 부적 | P0 |
| **B2** | 🎲 **보상 다시 뽑기** | 골드로 보상 3택1 재추첨 | P1 |
| **C1** | 🔥 **각성(Ascension) 0~10** | 클리어할 때마다 다음 난이도 해금, 누적 규칙 | P0 |
| **C2** | 📸 **런 결과 카드** | 빌드(파티·부적)·시드·각성 한 장 요약 + 시드 복사 | P1 |

## 3. 상세 규칙

### A1. 적 행동 예고
- 턴 시작(전투 시작·매 턴 종료·적 교체 직후)에 적 AI가 **이번 턴 행동을 확정**.
- 예고된 행동은 플레이어가 교체해도 **그대로 실행** → "상성 맞는 쪽으로 교체해 받아내기"가 성립.
- 표시: `🎯 다음 행동: 지진 · 예상 피해 ~18` / 치명 위험 시 붉은 `위험!` 배지 / 변화기는 `✨ 강화`·`💤 상태이상`.

### A2. 출발 축복 (5종 중 3개 제시)
| 축복 | 효과 |
|---|---|
| 🎁 희귀 부적 | 희귀 등급 부적 1개 |
| 🤝 첫 동료 | 1액트 희귀 에코링 1마리 합류 |
| 📦 보급품 | 골드 +100, 캡슐 +3, 포션 +2 |
| 🏋️ 특훈 | 스타터 레벨 +3 |
| 🩸 금단의 계약 | 영웅 부적 1개, 대신 골드·포션 0 |

### A3. 보스 페이즈
- HP 50% 이하가 되는 순간 1회: `💢 분노 각성!` — 공격·스피드 +1단계, EN 최대 충전, 상태이상 해제.
- 각성 5+ : 공격 +2단계.

### A4. 엘리트 접두사
| 접두사 | 효과 |
|---|---|
| 🌵 가시 | 받은 피해 15% 반사 |
| 💚 재생 | 매 턴 HP 6% 회복 |
| 🛡️ 철갑 | 받는 피해 -20% |
| 💨 신속 | 스피드 ×1.3 |
| 🦇 흡혈 | 준 피해 20% 흡수 |
| 💢 광폭 | HP 50% 이하에서 피해 +30% |
액트1 1개, 액트2~3 1~2개.

### B1. 신규 부적 (전설 4 · 영웅 3 · 희귀 4)
| 부적 | 등급 | 효과 | 빌드 축 |
|---|---|---|---|
| ❄️ 눈덩이 | 전설 | 전투 승리마다 피해 +3% 누적 | 장기 성장 |
| 🔁 메아리 방 | 전설 | 기술 사용 시 30% 확률로 EN 환급 | 궁극기 난사 |
| 🪶 불사조 깃털 | 전설 | 런당 1회, 전멸 시 전원 50% 부활 | 안전망 |
| 👑 미다스의 손 | 전설 | 보유 골드 100당 피해 +4% (최대 +40%) | 골드 빌드 |
| 💔 유리 심장 | 영웅 | 피해 +35%, 받는 피해 +20% | 하이리스크 |
| 🐺 외로운 늑대 | 영웅 | 파티 1마리일 때 피해 +50%, 받는 피해 -25% | 솔로 |
| ⚡ 과충전 | 영웅 | EN이 가득 찬 상태로 쓰는 기술 피해 +30% | EN 관리 |
| 🩸 선수필승 | 희귀 | 매 전투 첫 공격 치명타 확정 | 버스트 |
| 📚 수집가 | 희귀 | 파티 1마리당 피해 +4% | 풀파티 |
| 🧪 촉매 | 희귀 | 상태이상 걸린 적에게 피해 +30% | 상태이상 |
| 🍀 네잎클로버 | 희귀 | 전투 보상 선택지 +1 | 선택지 |
- 전설은 **보스 보상**에서만 등장. 등급 색: 일반(회)·희귀(청)·영웅(보라)·전설(금).

### C1. 각성 (누적)
| Lv | 규칙 |
|---|---|
| 1 | 적 체력 +10% |
| 2 | 엘리트 접두사 +1 |
| 3 | 상점 가격 +15% |
| 4 | 시작 포션·캡슐 -1 |
| 5 | 보스 분노 강화 (공격 +2단계) |
| 6 | 적 레벨 +1 |

# v0.3 — UI/UX 고도화 (도구 기반 아트)

> 원칙: **UI 그래픽을 코드로 그리지 않는다.** 일러스트는 Canva AI, 컨트롤 아이콘은 Lucide, 서체는 오픈 라이선스 게임 서체.

| 항목 | v0.2 | v0.3 |
|---|---|---|
| 배경 | CSS 그라디언트 | Canva AI 배경 일러스트 4종 + 가독성 오버레이 |
| 맵 노드 | 이모지 ⚔️🛒⛺ | Canva AI 3D 아이콘 8종 (방문=흑백, 이동 가능=바운스) |
| 아이템 | 이모지 🧪🔵 | Canva AI 아이콘 8종 (가방·상점·보상·전투 메뉴) |
| 속성 | 이모지 🔥💧 | Canva AI 엠블럼 8종 (칩·기술 카드·공명) |
| UI 컨트롤 | 텍스트 ← ✕ 🎒 | Lucide 벡터 아이콘 |
| 서체 | 시스템 폰트 | Pretendard + Jua + Lilita One (fonttools 서브셋 240KB) |
