# ECHOLING v0.4 — 사용자 게임 플로우 개선

> 방법: 신규 유저가 첫 런을 플레이하는 흐름을 단계별로 따라가며 "막히는 곳 / 실수하는 곳 / 이유 없이 기다리는 곳 / 왜 졌는지 모르는 곳"을 찾고, 각 지점에 해결책을 붙였다.

## 1. 사용자 여정 진단

| 단계 | 사용자 행동 | 문제 (마찰) | 심각도 |
|---|---|---|---|
| 맵 | 노드를 탭 | **탭 즉시 입장 → 오탭이 되돌릴 수 없는 실수**. 들어가기 전 위험도를 알 수 없음 | 🔴 높음 |
| 맵 | 경로 고민 | 내 파티가 보스를 이길 수준인지 알 수 없음 (시뮬상 사망 원인 1위 = 레벨 부족 상태로 보스 도착) | 🔴 높음 |
| 맵 | 선두가 빈사 상태로 전투 진입 | 첫 턴에 기절 → 억울함. 선두 교체 방법을 모름 | 🟠 중간 |
| 전투 | 연출 재생 대기 | 매 턴 2~4초 대기, 건너뛸 방법 없음 (반복 플레이 피로) | 🟠 중간 |
| 전투 | 예고 「위험!」, 포획 기회 | 시스템을 처음 보면 의미를 모름 (첫 전투 가이드는 한 번에 몰아서 보여줌) | 🟠 중간 |
| 패배 | 결과 화면 | **왜 졌는지 모름** → 다음 런 개선 동기 약함 | 🔴 높음 |
| 처음 실행 | 전투 속도 | 기본 x1이 느림 | 🟢 낮음 |

## 2. 개선안

| # | 개선 | 해결하는 문제 |
|---|---|---|
| F1 | **노드 확인 카드** — 탭하면 바로 들어가지 않고 정보 카드(노드 종류·예상 적 레벨·위험도·보상)를 띄운 뒤 「입장」 | 오탭, 정보 부족 |
| F2 | **위험도 배지** — 적 레벨 vs 내 선두 레벨로 「쉬움/적정/위험/매우 위험」 표시 | 경로 판단 |
| F3 | **보스 준비도** — 보스 카드에 「권장 Lv.12 · 내 최고 Lv.9 ⚠️」 | 레벨 부족 보스전 |
| F4 | **선두 빠른 교체** — 노드 카드에서 선두 HP가 낮으면 「건강한 동료를 선두로」 한 번에 | 빈사 선두 진입 |
| F5 | **연출 빨리 감기** — 전투 중 화면 탭하면 이번 턴 연출 즉시 완료 | 대기 피로 |
| F6 | **상황별 코치 팁** — 처음 겪는 순간에만 한 번 (첫 맵 / 첫 위험 예고 / 첫 포획 기회 / 첫 공명 / 첫 부적 / 선두 빈사) | 시스템 이해 |
| F7 | **패배 원인 리포트** — 마지막 일격(누가·무슨 기술·속성), 레벨 차이, 다음 런 추천 속성 | 실패 학습 |
| F8 | 신규 설치 기본 전투 속도 x2 | 템포 |
| F9 | **부적 아이콘 35종** — Canva AI 3×3 아이콘 시트 4장으로 생성 (35회 → 4회 생성) | 마지막 이모지 영역 제거 |

## 3. 검증
- [x] 위험도·준비도·추천 속성 계산은 순수 함수(`game/advice.ts`)로 분리해 단위 테스트 5종 (총 47 통과)
- [x] 노드 카드·빨리 감기·코치 팁·패배 리포트를 실제 화면에서 스크린샷으로 확인
- [x] 자동 플레이 오류 0

## 4. 검증 중 발견해 고친 문제
| 문제 | 원인 | 수정 |
|---|---|---|
| 코치 팁이 맵 하단 노드를 가림 | 말풍선을 엄지 영역(하단)에 배치 | 화면 상단으로 이동 |
| 「공명 발동」 팁 문구가 부정확 | 공명 증폭기 부적으로 1마리만으로도 발동 가능 | 조건 문구 일반화 |
| 패배 리포트가 복합 속성 보스에 엉뚱한 속성 추천 | 단일 속성 합집합으로 계산 | 실제 복합 배율 곱으로 계산 (새싹+대지 → 바람만) |
